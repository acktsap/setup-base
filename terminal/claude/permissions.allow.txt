# Host-neutral Claude Code permissions. Applied by apply-permissions.sh.
#
# `x:*` matches any command starting with x; a line without `:*` matches that
# exact string; `(` and `)` inside a line must be escaped as \( and \). No
# flag-level analysis, so a prefix authorizes every flag the command accepts —
# hence the hand-checking. Redirections are stripped before matching, and a
# chained command is allowed only if every segment is.
#
# The bar: no way to write a file or run another program. Kept out for failing it
# — uniq <in> <out>, tree -o, xxd <in> <out>, base64 -o, file -C -m, jmap -dump,
# sed -i, chmod, mysql, docker run/exec, git grep -O, git ls-remote
# --upload-pack, helm template --output-dir, gh auth status --show-token, curl -o,
# javac -processor (runs even with -version), and env/python3/xargs, whose whole
# function is running another program.
#
# Exceptions are marked where they appear:
#   BY EVIDENCE   the escape exists but appears in none of the recorded calls
#   BY DENY       the escape is carved out in permissions.deny.txt
#   BY DECISION   accepted with eyes open
#
# An unused grant is attack surface with no benefit, so no evidence of use is
# grounds for deleting a line.

# Gradle, task deliberately NOT pinned. Pinning was tried and abandoned: it meant
# enumerating task x JDK version x qualified/unqualified module form, ran past

# anyway — `JAVA_HOME=x ./gradlew publishRelease` bypasses any pin on bare

# logged. To reverse, use task-anchored globs and accept the prompts.
